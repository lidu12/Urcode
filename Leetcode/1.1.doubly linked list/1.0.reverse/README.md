### 📘 Question: Reverse ( **Interview Question** )

> Create a new method called reverse that reverses the order of the nodes in a doubly linked list, i.e., the first node becomes the last node, the second node becomes the second-to-last node, and so on.
> 
> 
> To do this, you'll need to **traverse the list** and change the direction of the **pointers** between the nodes so that they point in the opposite direction.
> 
> - Do **not** change the value of any node.
> - After reversal, update the `head` and `tail` pointers.
