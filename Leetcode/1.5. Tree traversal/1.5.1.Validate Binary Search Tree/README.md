# Validate BST

This code defines a Binary Search Tree (BST) and checks if it's valid.

- Uses in-order DFS to get node values in order.
- Confirms all values are in strictly increasing order.

## How It Works
- Insert nodes to build a BST.
- `dfs_in_order` returns node values in sorted order.
- `is_valid_bst` checks if values are strictly increasing.
