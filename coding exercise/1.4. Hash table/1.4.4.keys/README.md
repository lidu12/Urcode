## What does this function do overall?

✔️ It **looks through the entire hash table**.

✔️ It **finds every stored key**.

✔️ It **collects them in a list**.

✔️ It **returns that list** at the end.

✅ Example:

If your hash table has:

```
"apple" ➜ 5
"banana" ➜ 8
"orange" ➜ 12

```

✅ Then `keys()` ➜

```
["apple", "banana", "orange"]

```
