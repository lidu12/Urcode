r_contains for Binary Search Tree
This code implements a recursive search in a Binary Search Tree (BST).

✅ Purpose
To check if a given value exists in the BST.

✅ How It Works

Starts at the root.

If the value is equal → returns True.

If the value is smaller → searches the left subtree.

If the value is larger → searches the right subtree.

If it reaches None → returns False.
