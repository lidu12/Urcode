r_insert for Binary Search Tree
This code implements recursive insertion in a Binary Search Tree (BST).

✅ Purpose
To add a new value while keeping the tree sorted.

✅ How It Works

If the tree is empty → The new value becomes the root.

Otherwise:

If the new value is smaller → Go left.

If larger → Go right.

Repeat recursively until finding an empty spot.

Insert the new node there.
