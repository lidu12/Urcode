# Bubble Sort 

Bubble Sort is a simple sorting algorithm that repeatedly steps through the list, compares adjacent items, and swaps them if they are in the wrong order. The largest values "bubble" to the end with each pass.

✅ Time Complexity (Worst/Average): O(n²)  
✅ Space Complexity: O(1) (in-place)

---

## How It Works

1. Loop from the end of the list to the start.
2. For each pass, compare adjacent elements.
3. Swap them if they are in the wrong order.
4. Repeat until the list is sorted.
