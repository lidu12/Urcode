# Selection Sort

Selection Sort is a simple sorting algorithm. It works by repeatedly finding the smallest element in the unsorted part of the list and swapping it to the front.

## How It Works
1. Start at the first index.
2. Find the smallest value in the remaining list.
3. Swap it with the current index.
4. Repeat for each position.

## Example
Unsorted: [4, 2, 6, 5, 1, 3]
Sorted:   [1, 2, 3, 4, 5, 6]
